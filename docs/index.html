The pipeline

Two public steps. compose-org then deploy.

compose-org runs Research, Design, Build, Prove internally. Then zava-workspace-deploy ships the proven vertical to Azure in your chosen mode.

compose-org
Build vertical

One invocation. Internally runs four phases: Research (invokes research-company for factual profiling), Design (maps org-brief to actor archetypes and process profiles), Build (generates executable vertical pack with synthetic actor world), Prove (deterministic replay, causal invariants, proof manifest).

InputTarget name or domain
→
Outputverticals/<slug>/ + proof/manifest.json
> compose-org "Contoso Telco"
Research → Design → Build → Prove. Fail-closed proof gate. SKILL.md →
zava-workspace-deploy
Ship to Azure

Deploy the proven vertical to Azure Container Apps. Two modes: private-live (writable actor world, Durable Functions, auth required) or public-replay (baked tape, read-only, no Functions). Proof manifest gate required before any Azure mutation.

InputProven vertical + mode choice
→
OutputLive ACA workspace + App Insights telemetry
> zava-workspace-deploy --mode private-live
private-live or public-replay. Proof manifest required. SKILL.md →
